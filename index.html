Questions

A few useful things to know

What is included?

We clean the glass, frames and sills using pure water. If anything needs extra attention, add it to the quote notes.

Do I need to be home?

Not always. If access is agreed in advance, we can discuss whether the clean can be done while you are out.

How do I get a price?

Send the quote form with your property details. We will reply with a fixed quote before any clean is arranged.

What if the weather is bad?

If the weather makes a clean unsuitable, we will arrange a sensible time instead.
